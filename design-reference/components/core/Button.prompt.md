Standard action control — use `primary` (Campus Green) for the single main action per view, `secondary` (Collegiate Yellow) for event RSVPs and playful CTAs.

```jsx
<Button variant="primary" size="lg" icon="calendar-days">RSVP for Black Tie</Button>
```

Variants: primary, secondary, outline (ink border, inverts on hover), ghost, inverse (for use on blue). Sizes sm/md/lg. Labels are sentence case, verb-first, never ALL CAPS.
